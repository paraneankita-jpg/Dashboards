# Zudio Sales Dashboard

## Overview
This project is a Power BI dashboard built to analyze Zudio sales performance across key business dimensions such as revenue, orders, product contribution, time trends, and customer or regional segments. The dashboard is designed to help stakeholders monitor business performance quickly and support data-driven decision-making.

## Project Objective
The main goal of this dashboard is to provide a clear and interactive sales performance view that helps answer questions such as:
- How is overall sales performing
- Which categories or products contribute the most to revenue
- How do sales change over time
- Which segments, regions, or filters affect performance most strongly
- What summary KPIs should management track regularly

### 1. Home
A landing page that introduces the dashboard and provides report navigation.

### 2. Overview
The main analytics page containing KPI cards, slicers, and multiple chart types for business analysis.

## Key Features Included
Based on the report structure, the dashboard includes:
- KPI cards for high-level business metrics
- A combo chart for trend and comparison analysis
- A bar chart for ranked comparisons
- A donut chart for contribution analysis
- An area chart for trend visualization
- A treemap for category share analysis
- Slicers for interactive filtering
- Navigation elements and visual design assets

## Business Value
This dashboard can help business users:
- Track sales performance at a glance
- Identify top-performing categories or segments
- Monitor sales trends over time
- Compare actual performance across business dimensions
- Improve reporting speed versus manual spreadsheet analysis
